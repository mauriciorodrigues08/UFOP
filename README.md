# Ciência da Computação - UFOP
Repositório dedicado a armazenar os trabalhos práticos, algoritmos e projetos desenvolvidos durante o curso de Ciência da Computação na Universidade Federal de Ouro Preto (UFOP).

O objetivo deste espaço é manter um histórico organizado da minha jornada acadêmica, documentando a aplicação prática dos conceitos teóricos vistos em sala de aula ao longo dos semestres.

## Destaques
Aqui estão algumas das linguagens/tecnologias já estudadas por mim até o momento nesse repositório:

- **Linguagem C:** Implementação desde lógicas básicas, como sintaxe da linguagem (BCC201), até lógicas mais fundamentais, como gerenciamento de memória, estruturas de dados dinâmicas, árvores binárias de busca, filas, pilhas, listas encadeads (BCC202). Além de simulações de hardware como RAM, Cache e HD (BCC266) e Buscas e Ordenações em arquivos externos (BCC203).

- **C++:** Desenvolvimento de sistemas orientados a objetos, como um sistema bancário completo com cadastro de clientes e gerentes, operações de depósito/saque/transferência, conta poupança com rendimentos e cartão de crédito com fatura e parcelamento, além de persistência de dados em arquivos CSV (BCC221). Também apliquei algoritmos e estruturas de dados avançadas nas atividades do Mini CCO, envolvendo modelagem geométrica de árvores de bifurcação, otimização de posicionamento por grade e análise de complexidade dos algoritmos implementados (BCC402).

- **Java:** Desenvolvimento de um sistema de gerenciamento com interface gráfica (Swing) para análise de consumo energético, incluindo regressão linear, filtros dinâmicos combináveis, detecção de outliers e visualização gráfica interativa dos dados, aplicando os princípios de POO em uma arquitetura MVC completa (BCC221).

- **Pyton:** Utilização da linguagem para visualização de dados, com destaque para a renderização gráfica das árvores de bifurcação geradas nas atividades de C++ do Mini CCO, empregando bibliotecas como Pyvista e Pandas.

- **Programação Funcional (Haskell):** Aplicação de conceitos puros do paradigma funcional, incluindo imutabilidade, recursão, avaliação preguiçosa (lazy evaluation) e funções de alta ordem (BCC222).

- **Ferramentas e Ambiente:** Controle de versão na prática com **Git/GitHub** e configuração de ambiente de desenvolvimento utilizando **WSL** integrado ao **Visual Studio Code**.
